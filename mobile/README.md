# Mobile Application

This directory is a placeholder for the mobile application implementation.

## Future Implementation

This project template is designed to support mobile applications using technologies such as:
- React Native
- Flutter
- Ionic
- Native Android/iOS

## Authentication

The mobile app will integrate with the same Keycloak instance used by the web application, supporting:
- OAuth2 / OpenID Connect authentication
- SSO across web and mobile platforms
- Refresh token flow for mobile devices

## Getting Started

When implementing the mobile application, follow the same architectural principles as the backend and frontend:
- Feature-based modular structure
- Environment-based configuration
- Integration with existing Keycloak realm
