# Keycloak Theme

Custom Keycloak login theme (`project-template-theme`) built with [Keycloakify](https://www.keycloakify.dev/) (React + Vite). The account theme is not customized.

## Prerequisites

- Node.js 20+ and pnpm 10+
- JDK 17+ and Maven 3.8+ (Keycloakify uses Maven to package the JAR)

## Setup

```bash
pnpm install
```

## Scripts

| Script | Purpose |
|--------|---------|
| `pnpm dev` | Vite dev server |
| `pnpm build-keycloak-theme` | Build the theme JARs into `dist_keycloak/` |

## Using the theme

`pnpm build-keycloak-theme` generates two JARs in `dist_keycloak/`. The backend stack uses `keycloak-theme-for-kc-all-other-versions.jar`: `back/keycloak/Dockerfile` copies it into Keycloak's `providers/` directory, and the realm (`back/keycloak/template-realm.json`) sets `loginTheme` to `project-template-theme`.

The JAR is git-ignored. Build it before the first `docker compose up --build` in `back/`, and again after any theme change (then rebuild the Keycloak image).

## Structure

- `src/login/` - login theme: `KcPage.tsx` (page routing), `KcContext.ts`, `i18n.ts`, `pages/`, `css/`
- `src/kc.gen.tsx` - generated by Keycloakify, do not edit
