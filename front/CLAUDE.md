# CLAUDE.md - Frontend

Nuxt 4 app (Vue 3 Composition API) using file-based routing, auto-imports, SSR and Nuxt UI.

## Tech Stack

- **Framework**: Nuxt 4, TypeScript (strict)
- **UI**: Nuxt UI + Tailwind CSS
- **State**: `useState` (no Pinia)
- **Data fetching**: `useFetch` / `useAsyncData`
- **Server**: Nitro

## Rules

Detailed conventions live in `/.claude/rules/` (scoped to `front/**`):
`front-structure.md`, `front-conventions.md`, `front-best-practices.md`.

## Skills

- **nuxt-dev-guidelines** - Nuxt 4 reference (SSR, data fetching, SEO, server API)
- **frontend-dev-guidelines** - Vue 3 / TypeScript / Tailwind guidance
- **tailwindcss** - Tailwind CSS v4 patterns
